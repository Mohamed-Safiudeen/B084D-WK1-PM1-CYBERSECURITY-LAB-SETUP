# 🔐 Cybersecurity Lab Setup

## Project Overview
This project focuses on setting up a virtual cybersecurity lab using VirtualBox and Kali Linux for ethical hacking practice.

## Tools Used
- Oracle VirtualBox 7.2.22
- Kali Linux 2026.2
- Windows 11

## System Configuration

| Component | Details |
|---|---|
| Processor | Intel Core i7-8550U |
| RAM | 16 GB |
| Storage | SSD |
| Host OS | Windows 11 |
| Virtual Machine | Kali Linux |

## Network Configuration

| Component | Configuration |
|---|---|
| Network Type | NAT Network |
| Network Name | NatNetwork |
| Network Range | 10.0.0.0/24 |
| Gateway | 10.0.0.1 |
| Kali IP | 10.0.0.2/24 |
| DHCP | Disabled |

## Setup Procedure
1. Installed Oracle VirtualBox.
2. Downloaded and imported Kali Linux.
3. Created a NAT Network.
4. Connected Kali Linux to the NAT Network.
5. Configured the Kali IPv4 address.
6. Fixed network connectivity issues.
7. Verified internet access using Firefox.
8. Enabled bidirectional clipboard and drag-and-drop.
9. Created a VM snapshot.

## Verification
- Verified Kali Linux IP address.
- Confirmed internet connectivity by accessing YouTube through Firefox.
- Created a VirtualBox snapshot.
